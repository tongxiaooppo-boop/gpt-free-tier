## 1. 首頁與卡片分類

**做什麼**：首頁把功能分成四類卡片，點一張卡片就開始用。

步驟：

1. 打開程式，進入首頁「今天想做什麼？」。
2. 找到想用的分類，點一張卡片。
3. 想回首頁，按左上角的「GPT Free Tier」或「首頁」。

上方的導覽列有三個分頁：**首頁**、**紀錄**、**設定**。

### 拍照

| 卡片 | 用途 |
|---|---|
| 錯誤訊息解讀 | 貼錯誤訊息或截圖，說明原因與下一步 |
| 拍照翻譯 | 拍菜單、路標、說明書，輸出原文與譯文 |
| 拍照轉文字 | 把照片或截圖裡的文字轉成可複製的文字 |

### 文字

| 卡片 | 用途 |
|---|---|
| 自由對話 | 一般問答，可以接著聊 |
| 翻譯 | 整段翻譯，保留格式、數字與專有名詞 |
| 摘要 | 把文章整理成重點條列 |
| 改寫潤稿 | 換語氣或長度，不改事實 |
| 文法檢查 | 逐句找出錯誤並說明原因 |
| 易讀版改寫 | 把公文、通知、說明書改成白話短句，先列出你要做什麼 |

### 創作

| 卡片 | 用途 |
|---|---|
| 一稿多平台貼文 | 一段素材改成 Facebook、Instagram、X、Threads、LinkedIn 各一版 |
| 簡報大綱 | 文章變成逐頁大綱與講稿 |
| 點子產生器 | 禮物、命名、活動、標題，一次給 10 個並分類 |

### 生活

| 卡片 | 用途 |
|---|---|
| 諮詢前整理 | 找人諮詢前，把事情整理成時間軸、待補事實、要問的問題。只做整理，不是法律意見 |
| 條文白話 | 自己貼上一條法規條文，看白話說明。程式沒有法規資料，請先到全國法規資料庫複製現行條文 |
| 東西放哪 | 記下東西放在哪裡，忘了就問它（在首頁最下面的「生活工具」，詳見第 5 節） |

## 2. 卡片頁怎麼用

**做什麼**：照卡片上的欄位填好內容，按「開始」，就會得到結果。

步驟：

1. 從首頁點一張卡片。
2. 依序填欄位。欄位標題會寫「第 1 步、第 2 步」，標示「必填」的一定要填。
   - 文字欄位：直接輸入，或按「讀入 .txt／.md」把檔案內容讀進來（檔案上限 1 MB）。欄位下方會顯示字數與約略的 tokens 數。
   - 選項欄位：從下拉選單選。
   - 照片欄位：按選擇檔案或直接拍照。照片會先自動縮小，可以按「移除圖片」重選。
3. 想換模型：展開「進階：換模型」，選一個。每個選項後面會寫它屬於哪一組額度。不確定就不要改。
4. 按「開始」。這時按鈕會變成「停止」，想中斷就按它。
5. 結果會出現在「結果」區，回答下方會寫用了哪個模型、花幾秒、輸入輸出各多少 tokens。

### 結果下方的按鈕

- **複製**：把回答複製起來。
- **朗讀**：用你的裝置唸出回答（瀏覽器不支援時不會出現）。
- **下載 .md**：把這次的輸入與回答存成檔案（一次問答的卡片）。圖片不會存進檔案。
- **再來一次**：用同樣的內容重新問一次，會再用一次額度。

### 出錯時

- 畫面上方會出現紅色訊息，說明原因。
- 如果訊息旁有「重試」按鈕，表示這個錯誤可以再試一次，按下去即可。
- 如果寫「額度不足」，表示今天的免費額度不夠了，請等到台灣時間 08:00 重置，或見第 8 節。
- 如果寫「回答太長被截斷」，表示已達輸出上限，可以把內容分段再送。

### 自由對話的差別

自由對話可以一直接著聊，所以多了這些功能：

1. 上方會顯示完整對話，每則你說過的話旁邊有「編輯」，改完按「重新送出」。
2. 「開始新對話」：清掉目前畫面，從頭開始。
3. 「匯出整段對話」：把整段對話存成 .md 檔。

## 3. 去識別化（遮蔽個資）

**做什麼**：按「開始」前，程式會檢查你寫的文字有沒有個資，讓你決定要不要遮蔽。

程式找得到這四種：**身分證、電話、Email、統編**。

步驟：

1. 按「開始」。
2. 如果找到可能的個資，會跳出「送出前請確認：找到可能的個資」，列出找到的內容。
3. 選一個：
   - **遮蔽後送出**：把個資換成代號再送出。
   - **照原文送出**：不遮蔽，照原樣送出。
   - **返回修改**：回去自己改。
4. 沒找到個資就直接送出，不會跳出視窗。

要知道的事：

- 代號與原文的**對照表只存在記憶體**，不會送出、也不會存檔。
- 回答裡如果出現代號，**不會自動換回原文**，請自己對照。
- **人名、地址、帳號偵測不到**，請自己改成「甲、乙」或「某路某號」再送出。
- 圖片裡的個資也偵測不到，拍照前請自己注意。
- 偵測不一定完整，所有內容都會分享給 OpenAI，私密資訊還是不要輸入。

## 4. 對話紀錄頁

**做什麼**：找回以前的回答，或接著聊。

步驟：

1. 按上方導覽列的「紀錄」。
2. 清單會列出每筆紀錄的標題、使用的卡片與時間（今天的顯示幾點幾分，其他天顯示月／日）。
3. 點一筆，就會開啟當時的卡片頁，裡面有當時的輸入與回答。自由對話還可以接著聊。
4. 想刪除，按那一筆右邊的「刪除」，再確認。刪除後就找不回來。
5. 還沒有紀錄時，會顯示「還沒有對話紀錄，選一張卡片開始吧」。

紀錄只存在這台裝置的瀏覽器裡，最多保留 100 筆，超過時自動刪掉最久沒更新的。

## 5. 東西放哪

**做什麼**：記下「東西放在哪裡」，之後忘了可以問它。資料只存在這台裝置，最多 100 筆。

在首頁最下面的「生活工具」點「東西放哪」。

### 記一筆

1. 在「東西放在哪裡」輸入一句話，例如「健保卡放在客廳電視櫃第二層」。也可以按「麥克風」用說的。
2. 按「整理」。
3. 程式先在本機自己拆成「東西」和「位置」。拆得出來，就直接顯示「確認要記的內容」。
4. 拆不出來時，會問你：「本機沒把握。要把這句話送給 AI 嗎？會分享給 OpenAI，並使用小模型組額度。」
   - 按「送給 AI 整理」：才會用到 AI。
   - 按「自己填」：不用 AI，自己填東西和位置。
5. 檢查「東西」和「位置」，需要的話修改，按「儲存」。
6. 如果同樣的東西已經記過，畫面會提醒「儲存後會改成新位置」。
7. 如果已經記滿 100 筆，畫面會提醒會刪掉最久沒更新的那一筆。

### 找東西

1. 在「想找什麼」輸入或用說的，按「找」。
2. 本機找得到，就直接顯示答案，並標示「本機找到，沒有用到 AI」。
3. 本機沒把握時，會問你要不要把「清單裡的名稱與位置和你的問題」送給 AI。按「送給 AI 找」才會送出；按「不用了」就取消。
4. AI 的回答請以實際位置為準。

### 清單與刪除

1. 頁面下方的「清單」列出所有記錄，顯示更新時間。
2. 想刪除，按那一筆的「刪除」並確認。

## 6. 語音輸入與朗讀

**做什麼**：用說話代替打字，也可以讓程式把回答唸出來。

語音輸入：

1. 在文字欄位下方按「麥克風」（瀏覽器不支援時不會出現）。
2. 第一次使用，瀏覽器會問是否允許使用麥克風，按允許。
3. 開始說話，辨識出的文字會接在欄位後面。
4. 說完按「停止」。
5. 確認文字沒錯，再按「開始」送出。

語音朗讀：按回答旁的「朗讀」，想停就按「停止朗讀」。朗讀在你的裝置上進行。

注意：語音辨識由瀏覽器處理，Chrome 會送到 Google，Safari 會送到 Apple，不經過本程式，也不經過 OpenAI。

## 7. 設定頁

**做什麼**：放金鑰、選方案、填其他地方的用量、清除資料。按上方導覽列的「設定」進入。

### 金鑰

1. 到 [帳號設定步驟](SETUP.md) 第 4 步建立 API 金鑰並複製。
2. 在「API 金鑰」欄位貼上，按「儲存金鑰」。
3. 想刪掉，按「刪除金鑰」。共用電腦用完請記得刪。

### 方案

1. 在「方案」選你帳號的方案：Build 或 Launch／Grow。
2. 方案在 platform.openai.com 的 Limits 頁最上面可以看到。
3. 選 Launch／Grow 時會再跟你確認一次。不確定就留在 Build。

### 手動填用量

**什麼時候要填**：你今天在 Playground、其他程式或其他裝置也用了同一個組織的額度。

1. 到 platform.openai.com 的 Analytics → 使用情況，看今天各組用了多少 tokens。
2. 回到本程式設定頁的「今天在其他地方已用量」，大模型組、小模型組各填一個數字。
3. 按「儲存今日用量」。

### 使用告知與清除資料

1. 設定頁下方可以重看所有使用告知。
2. 「設定教學」按鈕可以回到申請步驟。
3. 「清除全部本機資料」：會刪除金鑰、對話、卡片結果與本機額度紀錄，之後要重新同意並重新設定。按下去會再確認一次。

## 8. 額度顯示怎麼看

**做什麼**：讓你知道今天的免費額度還剩多少。

1. 首頁的「今天的免費額度還剩」，分成大模型組與小模型組兩個百分比。
2. 在電腦版較寬的畫面，還會顯示「已用多少／上限多少」。
3. 每天台灣時間早上 8 點重新計算。
4. 數字包含你在設定頁手動填入的其他地方用量。
5. 這個數字只算得到這台裝置自己送出的量，加上你手動填的，並不是 OpenAI 後台的真實數字。請定期到 platform.openai.com 的 Analytics → 使用情況確認。
6. 送出前，程式會先預留額度，並且不動用最後 5%。額度不足時會直接拒絕，並告訴你已用多少、剩多少。
7. 大模型組（sol、astra）只有 250,000 tokens（Build 方案），很快就會用完，日常使用請優先選小模型組（luna、terra）。
